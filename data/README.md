# Wordle word lists

- `wordle-answers.txt` (~2,000 words): common 5-letter words from **SCOWL** (Spell Checker Oriented Word Lists) size levels 10–35, release 2020.12.07, with plurals ending in -s and -ed forms removed. © Kevin Atkinson et al., permissive licence (see `SCOWL-LICENSE.txt`). http://wordlist.aspell.net/
- `wordle-allowed.txt` (~16,000 words): SCOWL levels 10–70 combined with the 5-letter words from **dwyl/english-words** `words_alpha.txt` (Unlicense / public domain). https://github.com/dwyl/english-words
